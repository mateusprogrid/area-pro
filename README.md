# ÁreaPro

ÁreaPro is a Flutter application designed to calculate surface areas, estimate material waste, and provide construction cost projections.

## Features

- Triangle area calculator
- Rectangle area calculator
- Circle area calculator
- Material selection
- Automatic waste margin suggestions
- Material quantity estimation
- Cost estimation per square meter
- Responsive Material 3 interface
- Modern glassmorphism-inspired UI

## Supported Materials

- Flooring
- Wall covering
- Paint
- Wood
- Custom material

Each material provides a suggested waste percentage that can be manually adjusted.

## How It Works

1. Select a geometric shape.
2. Enter the required measurements.
3. Select the material.
4. Adjust the waste margin if necessary.
5. Enter the material price per square meter.
6. Calculate the required material and estimated cost.

## Example

For a rectangular surface:

```text
Base: 10 m
Height: 5 m
Material: Flooring
Waste margin: 10%
Price: R$ 85.00/m²

Area: 50.00 m²
Recommended material: 55.00 m²
Estimated cost: R$ 4,675.00
